# Kapilesh B - Static Personal Portfolio

A minimal, clean, and 100% static portfolio website built using semantic **HTML5**, **Bootstrap 5**, and custom **CSS3**.

## 📁 Project Structure

```
Portfolio/
│
├── index.html       # Static HTML file containing all sections
├── style.css        # Custom CSS for colors, typography & spacing
└── README.md        # Project documentation
```

## 🛠️ Technologies Used

* **HTML5:** Semantic elements (`<header>`, `<nav>`, `<section>`, `<main>`, `<footer>`).
* **Bootstrap 5 (v5.3.3 via CDN):** Responsive layout grid and clean styling.
* **Bootstrap Icons:** Lightweight vector icons.
* **Custom CSS3:** Minimalist light theme with collegiate Navy Blue (`#0f2b48`) accents.

## 📌 Sections

1. **Navbar:** Static responsive navigation menu linking directly to in-page section IDs.
2. **Hero:** Introduction, degree details, native location (Madurai), and quick action links.
3. **About Me:** Academic overview at PSNA College of Engineering and Technology.
4. **Education:** 3rd Year B.Tech IT card with core coursework.
5. **Skills:** Categorized skill badges (Languages, Web Dev, Databases & AI, Tools).
6. **Projects:** 4 featured project cards with technology tags:
   * *CollegeDocumentPortal*
   * *MovieWatchlist*
   * *StudyBuddy (AI Study Helper)*
   * *DecisionMirror*
7. **Contact:** Static contact information cards with direct `mailto:` link, LinkedIn link, and location details.
8. **Footer:** Simple copyright notice.
